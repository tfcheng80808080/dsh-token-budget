# 预算管理插件 · 真实 UI 端到端用例

> 目的：像真实用户一样打开 DSH 界面、点开预算胶囊、修改上限、触发阻断，
> 验证「界面 + Host + 会话」整条链路，而不是只测函数。

## 运行

```bash
cd token-budget/plugin
node tests/e2e.mjs            # E1–E5，非破坏性
node tests/e2e.mjs --send     # 追加 E6：真的发一条消息验证阻断
node tests/e2e.mjs --headed   # 有头浏览器，肉眼观察
```

结果写入 `tests/E2E-REPORT.md`，失败时非零退出。

## 环境隔离

- 使用独立 profile `~/.dsh/profiles/e2e`：`package.json` / `cordis.patch.yml` 从 desktop 复制，
  `node_modules` 软链到 desktop，因此加载的插件、模型配置与桌面端一致，但不会改动桌面实例的配置。
- 会话数据仍复用 `~/.dsh/sessions`（这是 DSH 的全局数据目录）。脚本会打开侧边栏**最后一排**会话
  （通常不是桌面端正在使用的那个），避免与正在运行的实例争用同一会话的写句柄。
- 浏览器通过 CDP（端口 9333）以真实鼠标/键盘事件驱动，不调用任何内部 API。

## 场景

| 编号 | 场景 | 步骤 | 预期 | 破坏性 |
|---|---|---|---|---|
| E1 | 胶囊可见 | 打开一个会话 | 输入框下方出现「预算管理」胶囊（带进度条） | 否 |
| E2 | 打开浮框 | 点击胶囊 | 出现二级浮框，标题「预算管理」，含 Token/金额、作用域、已用、上限、单位、按钮 | 否 |
| E3 | 应用上限 | 输入 `1` → 点「应用」 | 浮框提示「已更新」，且「上限：」立即显示新值（`… / 1`） | 否（仅写命令事件） |
| E4 | 恢复默认 | 点「恢复默认」 | 提示「已恢复默认」，「上限：」立即回到 `50.0k` | 否 |
| E5 | 关闭阻断 | 点「开启」开关 | 浮框变「已关闭（仅统计）」，胶囊 `data-off=1`（变淡） | 否 |
| E6 | 超限阻断 | `--send` 后在输入框发送消息 | 轮次被终止，会话出现「预算管理：预算已用尽，本轮任务已终止。」 | **是**：向所选会话追加一条用户消息与 `turn/end` 事件 |
| E7 | 不展示单价 | 打开浮框检查文案 | 浮框只显示已用/作用域/上限，不出现「单价」「入2」等价格明细 | 否 |

## 注意事项

- E6 会写真实会话：务必选一个**不常用**的会话，或在测试后删除该会话。
- 阻断发生在 `agent/pre-step`，因此 E6 **不会**触发模型调用（不会产生 token 费用）。
- 若桌面端同时打开着脚本选中的会话，命令会因写句柄冲突失败；换一个会话或关闭桌面端后重试。
- 脚本结束会杀掉自己启动的 dsh 与 Chrome；如中途异常退出，可手动 `pkill -f "profile e2e"`。
- 端口：dsh 用随机端口，Chrome 调试端口固定 9333。

## 与单元测试的分工

| 层级 | 文件 | 覆盖 |
|---|---|---|
| 单元/回归 | `tests/run.mjs`（41 条） | 投影折叠、视图计算、命令、阻断逻辑、节点定义、单位换算 |
| 端到端 | `tests/e2e.mjs`（7 条） | 真实界面渲染、点击交互、显示刷新、阻断提示 |

两者都应通过后再发布插件。
